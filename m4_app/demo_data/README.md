# Synthetic connectivity test only

The `.track`, `.nodes`, `.arcs` and `.route` files in this directory are deliberately **synthetic**, generated solely to verify the M4 API/UI flow. They are **not** evaluator trips, a trained model, or experimental evidence. Do not report demo scores as ML results.

For real evaluation, use `M4_MODE=trained`, supply the real private trip files on Laptop 1, and connect your independently trained M3 model. This repository never supplies private evaluator data.
